## 五条挖掘线各轮一遍（工序 3）

| 线 | 问什么 | 本项目的事实 | 是否成研究点 |
|---|---|---|---|
| 异常 | 哪个现象与预期不符？ | 措辞越像、数字越假；朴素稿措辞全对但 10/12 门禁失败 | 是 → §5.1 机制解释 |
| 取舍 | 放弃了什么？代价多少？ | 门禁可被「文体正确但内容空」的稿子满足；账本交叉只比总数 | 是 → §2.4 / §5.2 / §6 局限 |
| 复用 | 哪个自研件被多处复用？ | 账本被 4 个工具共享；图表数据格式被表与图共用 | 是 → §2.2 / §2.5 |
| 失败 | 哪些尝试无效？原因？ | 措辞清单、单一 checklist、把绿灯当交付标准 | 是 → §5.1 三条 |
| 成本 | 比常规省了什么？省多少？ | 0 GPU hours；载荷 159,076 字节，按需路由 | 是 → §3 表 1 |

**预算执行结果**：一条线只出一个主研究点，实际落了 4 个机制小节（2.2/2.3/2.4/2.5）+ 1 条舍弃候选，符合预算。

## 体裁判定（工序 1）

| 候选 | 判据 | 结论 |
|---|---|---|
| T（技术报告） | 需要报模型全账（预训练/后训练/基础设施） | 不适用：本技能不是模型 |
| **M（方法论文）** | 一个机制讲透 + 按演进组织 + 必备 `Unsuccessful Attempts` | **选 M** |
| A（应用） | 领域应用 + 独立 Related Work 豁免 | 不适用 |
| S（短报告） | 篇幅短、无附录 | 不适用：有 3 个附录 |

## 关键取舍记录

1. **不虚构消融**：§4.2 的表格是「按门禁定义推演」，不是「编译掉门禁重跑」。已在正文与表 caption 两处标注 `reasoned ... rather than measured`，并写进账本 `ev` 的 `verify`。
2. **不掩盖自家缺陷**：N4（无账本支撑的比较级断言）实测 12/12 通过，属工具假阴性。选择如实报告并写进摘要、§4.3、§5.2、§6 局限、表 2、表 4 六处，而不是删掉这个用例。
3. **不走「显著优于」**：全文 0 处比较级断言（`outperform/surpass/significantly better`），因为本技能的测量只有门禁计数，没有跨系统对照实验，`ev-009` 是唯一 compare 证据且仅用于同批次内部对比。
